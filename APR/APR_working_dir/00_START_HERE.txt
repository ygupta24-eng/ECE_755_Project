## 🎯 Floorplan Strategy

```
                    ┌──────────────────────────────────┐
                    │  w_in[0..3] (WEIGHT INPUTS)      │ ← TOP
                    │         ↓ ↓ ↓ ↓                  │
        ┌───────────┼──────────────────────────────────┼──────────┐
        │           │  ╔═══════════════════════════╗    │          │
        │           │  ║ FSM REGION (16 µm band)  ║    │          │
        │           │  ║ u_fsm control logic      ║    │          │
        │           │  ╚═══════════════════════════╝    │          │
        │   h_in0   │                                    │   h_in1  │
        │   h_in1   │  ┌──────────────────────────────┐ │          │
  RIGHT │    ↓      │  │ PE[0][0] PE[0][1] ... PE[0][3]│ ↓ RIGHT  │
        │           │  │ PE[1][0] PE[1][1] ... PE[1][3]│          │
        │  (h_data  │  │ PE[2][0] PE[2][1] ... PE[2][3]│          │
        │  enters   │  │ PE[3][0] PE[3][1] ... PE[3][3]│          │
        │   right)  │  └──────────────────────────────┘ │          │
        │           │         4×4 PE GRID (main)      │          │
        │ FIFO1     │                                    │          │
        │ FIFO2     │                                    │          │
        │ (left     │  psum_out0 ─────────────────────→ LEFT      │
        │  margin)  │  psum_out1 ─────────────────────→ (outputs) │
        │           │                                    │          │
        └───────────┼──────────────────────────────────┼──────────┘
                    │    v_in0  v_in1  (BOTTOM)        │ ← BOTTOM
                    └──────────────────────────────────┘
```

### Key Layout Principles

1. **FSM @ Top** (narrow band, 16 µm height)
   - Control signals flow downward
   - Minimizes latency to PE array
   
2. **PE Grid @ Center** (4×4 array, 120 µm × 55 µm)
   - Natural grid topology
   - High local PE-to-PE connectivity
   - ~8–10 µm per PE cell
   
3. **FIFOs @ Left Margin** (8 µm width)
   - u_fifo1 feeds row 1, u_fifo2 feeds row 3
   - Natural cluster with output drain
   
4. **Strategic I/O** (edges optimized for dataflow)
   - w_in → TOP (weight chain descends columns)
   - h_in → RIGHT (horizontal data for boundary)
   - v_in → BOTTOM (vertical data for boundary)
   - psum → LEFT (accumulator output drain)
